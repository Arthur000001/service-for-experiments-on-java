# 🗂️ Java Collections Full Hierarchy (с самого корня)

**java.lang.Iterable** – Интерфейс, реализуемый всеми коллекциями, по которым можно итерироваться.  
└── **java.util.Collection** – Основной интерфейс для всех коллекций  
    ├── **java.util.List** – Упорядоченные коллекции, допускающие дублирование элементов  
    │   ├── `ArrayList` – Реализует динамический массив  
    │   ├── `LinkedList` – Реализует двусвязный список  
    │   └── `Vector` – Устаревший синхронизированный аналог `ArrayList`  
    │       └── `Stack` – Реализует стек, расширяя `Vector`  
    ├── **java.util.Set** – Коллекции, не допускающие дублирование элементов  
    │   ├── `HashSet` – Реализует множество на базе хэш-таблицы  
    │   │   └── `LinkedHashSet` – Сохраняет порядок вставки элементов  
    │   └── `TreeSet` – Реализует множество на базе красно-черного дерева  
    └── **java.util.Queue** – Очереди (в том числе двухсторонние)  
        ├── `PriorityQueue` – Очередь с приоритетом на базе кучи  
        └── `Deque` – Двусторонняя очередь  
            └── `ArrayDeque` – Реализует двухстороннюю очередь на базе массива

---

**java.util.Map** – Интерфейс, не реализует `Collection`, но часто рассматривается вместе  
├── `HashMap` – Хэш-таблица для хранения пар ключ-значение  
│   └── `LinkedHashMap` – Сохраняет порядок вставки  
└── `TreeMap` – Отображение на базе красно-черного дерева с сортировкой

---

# ⚙️ Сравнение производительности коллекций в Java

| Коллекция     | Добавление                      | Удаление             | Поиск                                 | Поддержка порядка            |
|:--------------|:--------------------------------|:---------------------|:--------------------------------------|:-----------------------------|
| ArrayList     | Быстрое (амортизированное O(1)) | Среднее (O(n))       | Быстрый (O(1) при доступе по индексу) | Да (по индексу)              |
| LinkedList    | Быстрое (O(1))                  | Быстрое (O(1))       | Медленный (O(n))                      | Да (по порядку добавления)   |
| HashSet       | Очень быстрое (O(1))            | Быстрое (O(1))       | Очень быстрый (O(1))                  | Нет                          |
| LinkedHashSet | Быстрое (O(1))                  | Быстрое (O(1))       | Очень быстрый (O(1))                  | Да (по порядку вставки)      |
| TreeSet       | Медленнее (O(log n))            | Медленное (O(log n)) | Быстрый (O(log n))                    | Да (сортировка по сравнению) |
| HashMap       | Очень быстрое (O(1))            | Быстрое (O(1))       | Очень быстрый (O(1))                  | Нет                          |
| LinkedHashMap | Быстрое (O(1))                  | Быстрое (O(1))       | Очень быстрый (O(1))                  | Да (по порядку вставки)      |
| TreeMap       | Медленное (O(log n))            | Медленное (O(log n)) | Быстрый (O(log n))                    | Да (сортировка по ключу)     |
