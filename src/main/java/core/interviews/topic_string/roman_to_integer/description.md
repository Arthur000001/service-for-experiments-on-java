## 13. Римские цифры в целое число
**Уровень сложности:** Лёгкий  
**Темы:**  
**Компании:**  
**Подсказка:**

Римские цифры представлены семью различными символами: `I`, `V`, `X`, `L`, `C`, `D` и `M`.

| Символ | Значение |
|--------|----------|
| I      | 1        |
| V      | 5        |
| X      | 10       |
| L      | 50       |
| C      | 100      |
| D      | 500      |
| M      | 1000     |

Например:
- Число 2 записывается как `II` — просто два сложенных единичных символа.
- Число 12 записывается как `XII`, то есть `X + II`.
- Число 27 записывается как `XXVII`, то есть `XX + V + II`.

Римские цифры обычно записываются от наибольшего к наименьшему слева направо. Однако для некоторых чисел применяется правило вычитания. Например, число 4 записывается как `IV`, а не `IIII`, потому что единица стоит перед пятёркой — её нужно вычесть. То же самое с числом 9 — `IX`.

Существует шесть случаев, когда применяется вычитание:

- `I` может стоять перед `V` (5) и `X` (10), чтобы образовать 4 и 9.
- `X` может стоять перед `L` (50) и `C` (100), чтобы образовать 40 и 90.
- `C` может стоять перед `D` (500) и `M` (1000), чтобы образовать 400 и 900.

### Задание
Дана строка `s`, представляющая римское число. Преобразуйте его в целое число.

### Примеры:

#### Пример 1:
**Ввод:**  
`s = "III"`  
**Вывод:**  
`3`  
**Пояснение:**  
`III = 3`

#### Пример 2:
**Ввод:**  
`s = "LVIII"`  
**Вывод:**  
`58`  
**Пояснение:**  
`L = 50`, `V = 5`, `III = 3`

#### Пример 3:
**Ввод:**  
`s = "MCMXCIV"`  
**Вывод:**  
`1994`  
**Пояснение:**  
`M = 1000`, `CM = 900`, `XC = 90`, `IV = 4`

### Ограничения:

- `1 <= s.length <= 15`
- `s` содержит только символы `'I'`, `'V'`, `'X'`, `'L'`, `'C'`, `'D'`, `'M'`
- Гарантируется, что `s` — это корректное римское число в диапазоне от `1` до `3999`.
