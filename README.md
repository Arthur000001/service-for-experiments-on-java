# Java Experiments Project

## 📚 Description
This project is a structured set of experiments and educational materials for studying core Java concepts. It covers fundamental algorithms, data structures, Java language features, and advanced topics like garbage collection and stream API.

---

## 📦 Project Structure

### Algorithms
- `bubble_sort_and_binary_search` — Bubble Sort & Binary Search Implementation.
- `insertion_sort` — Insertion Sort Algorithm.
- `quick_sort` — Quick Sort Algorithm.

### Data Structures
- `array_list` — Custom ArrayList Implementation.
- `circular_queue` — Circular Queue Example.
- `deque` — Double-Ended Queue Implementation.
- `linked_list` — Linked List Implementation.
- `map` — Hash Table Example.
- `stack` — Stack Implementation.
- `tree_traversal` — Tree Traversal Control Logic.

### Exception Handling
- `exception` — Experiments with Java Exceptions.

### Garbage Collection
- `garbage_collector` — GC Testing and Profiling (`GcTest`).

### Object-Oriented Programming
- `object` — Examples of Object-Oriented Programming Concepts.

### Java Streams API
- `stream` — Practical Examples Using Streams:
    - `CaseCollectors`, `CaseIntermediate`, `CaseTerminal`
    - Utilities and Experimental Cases.

### Models
- `model` — Data Models:
    - `Employee`, `Person`.

### Main Entry Point
- `Main` — Project Start Point.

## 🚀 How to Run
1. Open the project in IntelliJ IDEA (or any preferred IDE).
2. Run `Main.main()` to start the experiments.
3. Explore individual experiments through their corresponding `StartExperiments` classes.
