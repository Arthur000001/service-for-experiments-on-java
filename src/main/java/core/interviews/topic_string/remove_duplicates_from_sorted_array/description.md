### Задание

Дан целочисленный массив `nums`, отсортированный в **неубывающем порядке**. Необходимо **удалить все дубликаты на месте**,  
так чтобы **каждый уникальный элемент встречался только один раз**, при этом **сохранив относительный порядок элементов**.  
Затем вернуть **количество уникальных элементов** в массиве.

Предположим, что количество уникальных элементов — это `k`. Чтобы решение было принято, нужно выполнить следующие условия:

1. Изменить массив `nums` таким образом, чтобы **первые `k` элементов** содержали **уникальные элементы в порядке их первоначального следования**.
2. Остальные элементы массива не важны — их значения могут быть любыми, как и размер массива.
3. Вернуть число `k`.

---

### Проверка решения

Автоматическая система проверяет решение следующим образом:

```java
int[] nums = [...]; // Входной массив
int[] expectedNums = [...]; // Ожидаемый результат с правильной длиной

int k = removeDuplicates(nums); // Вызов вашей функции

assert k == expectedNums.length;
for (int i = 0; i < k; i++) {
    assert nums[i] == expectedNums[i];
}
